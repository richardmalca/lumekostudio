# 🚀 LumekoStudio

He creado esta página de presentación para **LumekoStudio**. Es un diseño minimalista y moderno que busca capturar la esencia de la marca.

El proyecto cuenta con una interfaz totalmente responsiva, asegurando una experiencia de usuario fluida tanto en dispositivos móviles como de escritorio. Para darle un toque único, he incorporado efectos visuales como una animación de resplandor en el título y un sutil efecto de cristal en los botones.
